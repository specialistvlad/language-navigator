# Roadmap

Project phases. The topic plan, in study order, lives in
[languages/curriculum.yaml](languages/curriculum.yaml); each topic's status lives in its
`topic.yaml` and shows in the web app.

Build order: pilot topics first, then all A0–A1 topics in both languages, then A2, then B1.
One topic at a time; each topic is approved before the next one starts.

## Phases

| Phase | Work | Status |
|---|---|---|
| 0 | Conventions, JSON Schemas, topic template | draft |
| 1 | Pilot topics `en.tenses.simple-tenses`, `es.conjugation.presente-regular`; web review app | in progress |
| 2 | All topics by level: A0–A1 → A2 → B1 | todo |
| 3 | Shared references: CEFR levels, grammar terms, EN–ES contrasts | todo |
| 4 | Static web build with cheatsheets, sitemap and PDF template | in progress |
| 5 | Public web app | todo |
